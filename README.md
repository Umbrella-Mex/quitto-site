# QuittoPay — site

Páginas públicas do QuittoPay: landing page, política de privacidade e termos de uso.

- `index.html` — landing page
- `privacy-policy.html` / `terms.html` — documentos legais
- `open-account.html` — atalho que abre o app (deep link) ou leva à Play Store
- `styles.css` — design system do site (paleta alinhada ao app)

Publicado em GitHub Pages: https://quittopay.com.br
